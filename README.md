# BSS Index 🪿🍯

**BSS Index** — это интерактивный прайс-лист и калькулятор сделок для игры Roblox **Bee Swarm Simulator (BSS)** на русском языке.

Сайт помогает трейдерам оценивать стоимость стикеров, ваучеров и скинов, а также рассчитывать прибыльность обменов в реальном времени.

## Особенности 🌟
* 📊 **Калькулятор сделок**: добавьте предметы с двух сторон обмена и получите автоматический вердикт (*Слив*, *Убыточный трейд*, *Честный трейд*, *Выгодный трейд*, *Огромный плюс*).
* 📦 **Полная база предметов**: 289 игровых предметов с реальными изображениями, описаниями и рейтингами спроса.
* 📈 **Интерактивные графики**: визуализация изменения ценности предметов за последние 6 недель с помощью сглаженных SVG sparkline-графиков.
* ⚡ **Spotlight-поиск**: быстрый поиск предметов по нажатию `Ctrl + K` / `⌘K`.
* 🎨 **Премиальный дизайн**: Bento-стиль сетки с эффектом мышиного неонового свечения (Mouse Glow) под цвет редкости предмета.

## Технологический стек 🛠️
* React + TypeScript
* Tailwind CSS
* Framer Motion (анимации)
* Lucide React (иконки)
* GitHub Actions (автоматический деплой)


## 🔄 Автообновление цен

Цены подтягиваются автоматически — GitHub Actions запускает workflow
**Update prices** каждый день в **06:17 UTC** (и вручную через вкладку Actions).

```
bssmvalues.com/api/values
   └─> scratch/fetch_live_values.py   скачивает сырые данные
        └─> scratch/update_prices.py  применяет их к bot/items.json
             └─> git commit + push    триггерит деплой на Vercel
                  └─> npm run build   пересобирает страницы, API, виджеты
                       └─> бот видит новый SHA и сам пишет об обновлении в Discord
```

### Где лежат данные

| Файл | Роль |
|---|---|
| `bot/items.json` | **источник истины**, 330 предметов |
| `public/data/items.json` | рантайм-данные для сайта, генерируются при сборке |
| `dist/api/**` | публичный JSON API (`/api/values.json` и др.) |
| `dist/item/**` | 330 статичных страниц предметов (EN) |
| `dist/ru/item/**` | те же страницы на русском |
| `dist/w/**` | 330 встраиваемых виджетов |

Данные **не вшиты в JS-бандл** — они отдаются отдельным файлом и кешируются
независимо от кода. Бандл: 661 КБ (185 КБ gzip), данные: 30 КБ gzip.
